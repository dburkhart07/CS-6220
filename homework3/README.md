## Running `homework3.ipynb`

From the `homework3` directory, create and activate a virtual environment, install the dependencies, and launch Jupyter:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter notebook homework3.ipynb
```

In Jupyter, select **Kernel -> Restart Kernel and Run All Cells**.
